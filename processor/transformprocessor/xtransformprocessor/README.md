# Transform Processor Profiles

This module houses the transform processor's profiles API: `WithProfileFunctions` and
`DefaultProfileFunctions`.

Profiles support is under active development and is versioned independently at 0.x so that it sits
outside of the transform processor's stability guarantees. See the
[transform processor README](../README.md#processortransformenableprofiles) for the
`processor.transform.enableProfiles` feature gate that controls profiles support.
